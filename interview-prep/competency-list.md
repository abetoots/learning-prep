# Readiness rubric — what "ready" means, in testable terms

This is the competency list. Read it tonight (Week 0). Score every row in week 1 for a baseline and again in week 6 — you cannot see progress without the first score. Every week's work should visibly move a row.

**Pass = every row at "ready".** Any "not yet" adds a week of that kind of work. You don't get to move the bar because you ran out of weeks; an honest "not yet" is the point of having one.

| Signal | Ready looks like | Evidence | Week 1 | Week 6 |
|---|---|---|---|---|
| Architecture pitch | ≤5-min walkthrough, unprompted coverage of tenancy, ingestion, sends, metrics; concedes both known gaps before being asked | Recording, week 5–6 | | |
| Conceptual depth | 10 randomly drawn question-bank items: 8+ hit the answer-pointer essentials without notes | 10-item draw, graded in the score columns | | |
| Transfer | A never-seen design prompt produces a complete 45-min artifact with explicit tradeoffs | Week 4 & 6 artifacts | | |
| Coding | Unseen LeetCode medium in ≤25 min, talking aloud, correct + complexity stated, 3 of last 4 attempts | Timed logs | | |
| Recall | Anki mature retention ≥85%; core complexities/definitions instant | Anki stats | | |
| Behavioral | 5 STAR stories; any of ~20 standard prompts mapped to one in <5s | Mock #2 + drill | | |
| AI-collaboration judgment | On a PR with **known ground truth**: ≥2 of the known invariant defects found in 45 min, **with ≤1 false positive** (a "defect" that isn't one). Delegation boundary stated unprompted in <2 min | Week 4 artifact — answer key written *before* the review, findings graded against it | | |
| Failure-mode fluency | Can diagram outbox/claim/CAS crash windows from a blank page and name each residual | Week 3 diagrams | | |
| Calibration | Confidence ratings track actual scores within ~15 points; no category where you're systematically overconfident | `error-log.md` confidence/scored columns, weeks 3–6 | | |
| Simulation | Full mock loop completed; debriefs show no repeated failure pattern from earlier mocks | Week 6 debriefs | | |

Score a cell `ready` / `not yet` / `—` (not attempted), with the date.

**If you have to cut a row, cut AI-collaboration's review round first** and keep the two week-5 STAR skeletons. The verbal probe ("how do you use AI?") is near-universal; the formal review round is the part resting on weaker evidence.
